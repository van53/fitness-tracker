# 🏋️‍♂️ Фітнес-трекер (Fitness Tracker)

Сучасний Full-stack вебзастосунок для відстеження фізичної активності, ведення довідника вправ та моніторингу особистого прогресу. Проєкт розроблено з акцентом на продуктивність, зручний UI/UX та масштабовану архітектуру.

---

## 🚀 Ключовий функціонал

* **Керування тренуваннями:** Створення, перегляд та видалення записів про активність із підрахунком загального часу.
* **Довідник вправ:** Ведення бази даних вправ із категоризацією за групами м'язів.
* **Профіль користувача:** Інтерактивний дашборд для редагування особистих параметрів (вік, зріст, вага) та завантаження персонального аватара.
* **Оптимізований пошук та пагінація:** Швидка фільтрація даних як на стороні клієнта, так і на стороні сервера.
* **Сучасний адаптивний UI:** Інтерфейс побудовано на Material Design v6, що гарантує ідеальне відображення на мобільних та десктопних пристроях.

---

## 💻 Технологічний стек

* **Frontend:** React 18 (Vite), TypeScript, Material UI (MUI v6), React Hook Form + Zod, Axios.
* **Backend:** NestJS, TypeScript, Multer (обробка `multipart/form-data`).

---

## 📡 API Ендпоінти

* **GET /workouts?page=1&limit=5&search=text:** Отримати список тренувань (з пагінацією та пошуком).
* **POST /workouts:** Створити нове тренування.
* **DELETE /workouts/:id:** Видалити тренування з бази даних.
* **GET /exercises:** Отримати повний список вправ довідника.
* **POST /exercises:** Додати нову вправу до бази даних.
* **DELETE /exercises/:id:** Видалити вправу з довідника.
* **POST /upload:** Завантажити файл зображення та отримати його URL.

---

## 🛠 Як запустити локально

* **Вимоги:** Для коректної роботи проєкту на вашому комп'ютері має бути встановлений Node.js.
* **Крок 1 (Backend):** Зайдіть у папку `backend`, виконайте команду `npm install`, а потім запустіть сервер через `npm run start:dev`. API буде доступне за адресою `http://localhost:3000`.
* **Крок 2 (Frontend):** У новому терміналі зайдіть у папку `frontend`, виконайте команду `npm install` та запустіть клієнт через `npm run dev`. Застосунок відкриється за адресою `http://localhost:5173`.
